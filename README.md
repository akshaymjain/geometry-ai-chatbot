# geometry-ai-chatbot

A primitive natural language processing (NLP) geometry assistant built in Python.

## Features
- Intent Detection: Uses string parsing operators to analyze conversational English commands.
- Contextual Routing: Rules-based data control routes inputs dynamically to specific calculation modules.
- Input Validation Guardrails: Programmatically intercepts illegal values (negative or zero radius) to prevent formula failures.
- Advanced Sphere Mathematics: Calculates Volume, Circumference, Area, and Total Surface Area with maximum precision.
